3週目: アルティメットじゃんけん（構想）

じゃんけんに戦略・判断・心理戦を持ち込む競技版。ターンごとにレギュレーションが変化し、先に20ポイントへ到達したプレイヤーが勝者です。

コンセプト

1. 通常のじゃんけんで勝敗を決め、得点を積み上げる。

2. 毎ターンのレギュレーションで読み合いを発生させる。

3. 高得点を狙うか、失点回避を優先するかを選ぶ。

ゴールは運だけでなく、期待値の判断と相手の心理を読むこと。

確定レギュレーション

WIN CONDITION

勝利条件

  • 先に20ポイントへ到達した側の勝利。
  • 同ターンで両者20以上の場合は高得点側が勝利。
  • 同点ならサドンデス1本で決着。
BASE POINT

通常得点

  • 勝ち: 2点
  • あいこ: 1点
  • 負け: 0点
REGULATION CARDS

採用カード一覧（9種）

カード名 効果 メモ
ボーナスハンド: グー グーで勝利したら追加得点。 読み合いを作る主軸。
ボーナスハンド: チョキ チョキで勝利したら追加得点。 手を偏らせる圧力。
ボーナスハンド: パー パーで勝利したら追加得点。 逆読みを誘発。
逆風: グー グーで負けると追加失点。 リスク管理用カード。
逆風: チョキ チョキで負けると追加失点。 守備判断を強化。
逆風: パー パーで負けると追加失点。 終盤の選択圧に効く。
チャレンジ 攻めを通したときに追加得点。 高リスク高リターン枠。
リベンジ 前ターンで負けた側が勝利で +2。 逆転チャンス。
クライマックス 15点到達以降、抽選で発動し +1。 シークレット効果として開示。

1ターンの追加ボーナス上限は +5。表示は「基本点 + ボーナス内訳 = 獲得点」で統一する。

通信対戦の実装方針

対戦モデル Week2と同じ通信対戦UIを継承。ルーム作成、参加、同期表示の流れで実装する。
マッチング 待機キューから2人を自動でペアにし、対戦ルームを生成する。
同期内容 手の提出、レギュレーション状態、得点、勝敗ログをリアルタイムで共有する。
進行管理 ホスト端末依存なし。状態遷移を共通ルールで管理して切断時も再接続できるようにする。
通信対戦で遊ぶ CPU対戦（テスト）
Firebase Realtime Databaseを利用したリアルタイム対戦を実装済み。ルームコード共有で即マッチングできます。
