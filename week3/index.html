3週目: アルティメットじゃんけん（構想）

じゃんけんに戦略・判断・心理戦を持ち込む競技版。ターンごとにレギュレーションが変化し、先に20ポイントへ到達したプレイヤーが勝者です。

コンセプト

1. 通常のじゃんけんで勝敗を決め、得点を積み上げる。

2. 毎ターンのレギュレーションで読み合いを発生させる。

3. 高得点を狙うか、失点回避を優先するかを選ぶ。

ゴールは運だけでなく、期待値の判断と相手の心理を読むこと。

確定レギュレーション

WIN CONDITION

勝利条件

  • 先に20ポイントへ到達した側の勝利。
  • 同ターンで両者20以上の場合は高得点側が勝利。
  • 同点ならサドンデス1本で決着。
BASE POINT

通常得点

  • 勝ち: 2点
  • あいこ: 1点
  • 負け: 0点
BONUS RULE

リベンジ

  • 前ターンで負けたプレイヤーが対象。
  • そのターンで勝利したら追加で +2点。
  • あいこ・敗北時は加点なし。
SECRET RULE

クライマックス

  • どちらかが15点以上で毎ターン発動抽選。
  • 発動時はシークレット効果として +1点。
  • 発動有無は結果表示時に開示。

1ターンの追加ボーナス上限は +5。表示は「基本点 + ボーナス内訳 = 獲得点」で統一する。

通信対戦の実装方針

対戦モデル Week2と同じ通信対戦UIを継承。ルーム作成、参加、同期表示の流れで実装する。
マッチング 待機キューから2人を自動でペアにし、対戦ルームを生成する。
同期内容 手の提出、レギュレーション状態、得点、勝敗ログをリアルタイムで共有する。
進行管理 ホスト端末依存なし。状態遷移を共通ルールで管理して切断時も再接続できるようにする。
Week2 通信ルーム版を確認 Week2 紹介ページへ
実装フェーズでは、GitHub Pagesをフロント配信として利用しつつ、マッチングと対戦同期は外部リアルタイム基盤で担当する構成を想定しています。
